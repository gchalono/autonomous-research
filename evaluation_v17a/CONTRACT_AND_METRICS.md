# Evaluation contract and mathematics — v17a.1

Written before scorer implementation. This is a measurement apparatus, not an engine accuracy result. All shipped labels/sources are developer-authored synthetic mechanics fixtures; no independent human labels exist.

Entities have globally unique IDs across types. A Dataset carries tasks, frozen sources, reference answers, engine reports, atomic factual claims, citations, passages, claim annotations, per-relationship annotations, auditor decisions, subquestion judgments, numerical references/judgments, abstentions, traces, and contradictions. Foreign keys resolve within the appropriate task/report. Source offsets and claim offsets are Python Unicode code-point half-open intervals into exact UTF-8-decoded strings; no normalization at anchoring. Passage text must equal the entire source slice. Synthetic source provenance is explicit. Dataset SHA-256 seals canonical JSON of all dataset fields except its own digest. Changing any task, snapshot, reference or label invalidates that seal; new frozen versions must be minted, not silently resealed in a study. Provenance attestations are records, not proof of reviewer independence.

## Claim inventory protocol

An inventory reviewer, blinded to engine classifications/audit decision, reads every narrative field (summary, findings, claims, limitations/dependencies) and records every independently testable factual proposition, including implicit numerical/comparative claims. Normative statements are marked nonfactual, not treated as supported facts. Each claim has exact report location, one proposition, materiality and a canonical proposition key. Compound statements must be split with overlapping location spans permitted but different proposition keys. Unsupported compound inventories are invalid. Exact normalized duplicate text or repeated proposition keys within one report are rejected, not rewarded; semantically paraphrased duplicates require reviewer detection. Splitting one proposition into cosmetic fragments is forbidden. Materiality is judged before support labels: critical changes the main decision; material changes a required conclusion; minor affects detail; not_applicable is reserved for non-scored contexts.

The inventory certificate records all/submitted/annotated IDs separately and a complete, gap-free partition of the report text into factual spans (claim IDs) and nonfactual spans. Each factual location must be covered and each factual segment must point to claims actually overlapping it. Missing submission/annotation is visible, never removed from inventory denominators. Certification requires reviewer, method and an explicit completeness attestation. False certification cannot be detected mechanically; unknown factual sentences mislabeled nonfactual require independent audit. Until completeness is independently established, no comprehensive report accuracy may be claimed. Production adapter renders all narrative fields deterministically and returns an UNCERTIFIED inventory template; it does not invent claims, entailment or adjudication.

Independent reference protocol: construct reference answers and subquestions from frozen sources before seeing engine output. Two qualified annotators where feasible; blind to candidate identity and auditor decisions. Preserve independent labels, disagreements, adjudication notes and unresolved labels; freeze a final version with named responsibility. Never simulate human independence by multiple model calls. Synthetic fixtures use synthetic_developer provenance and cannot receive independent_human status merely because a scorer ran.

## Metrics

Each metric returns numerator, denominator, rational value (or null), status and exclusions/coverage notes. Denominator zero yields undefined, never 0 or 1. Invalid input yields invalid_input with errors, not metrics. A structurally valid input with incomplete inventory or nonfinal/missing labels yields insufficient_adjudication. No composite overall accuracy/reliability score. Micro totals are descriptive correlated claim counts; task-macro results are used for inference.

For inventoried factual claims N: factual_correctness = final correct / final claims labeled correct, incorrect or partially_correct. Partial receives no full credit. Indeterminate and not_evaluated remain outside that denominator and are visible via adjudication_coverage = decisive final labels / N. annotation_coverage = claims with any annotation / N; submission_coverage = submitted / N. Inventory completeness is a separate prerequisite, never inferred from these ratios.

claim_support = final fully_supported claims with >=1 final supporting correct-source-and-passage relationship / N. citation_coverage uses the same adequacy rule (explicit separate metric; intentionally equal under v1 rubric). Partial, unsupported, contradicted, unverifiable and missing citations earn no full credit. Missing/nonfinal labels stay in N. citation_presence = claims with any valid citation / N is diagnostic only.

citation_precision = final supporting correctly attributed unique (claim, source, start, end) relations / final evaluated unique relations. Nonfinal relations excluded and relation_adjudication_coverage reported. Duplicate citation IDs invalid; duplicate relations with distinct IDs deduplicated. Duplicate relations must have identical judgments; disagreement is invalid input. Citation presence does not establish truth; truth may be correct while support is unsupported, or incorrect with a genuine citation. Final fully_supported labels inconsistent with citation/relationship judgments are invalid metadata.

Required subquestion completeness = final fully answered required questions / all required subquestions for each report. Omitted/partial/nonfinal judgments earn no full credit. Contradiction handling reports four separate rates: identified, accurate, addressed, reflected, each / known material contradictions in the task; absent report judgments earn none. Source truth is adjudicated, not guessed by text matching.

Auditor gold defect status is independently annotated per report (defective, clean, unresolved) with final/provisional/disputed/unresolved/missing status. A final clean label requires complete inventory, decisive final factual/support judgments, all required subquestions answered, correct numerics and all material contradictions handled, and no unresolved critical/material issue. Structural consistency is checked. report_false_approval = approved gold-defective reports / final gold-defective reports with a recorded decision; false_rejection = non-approved gold-clean reports / final gold-clean reports with decision. Non-approve includes corrections_required/inconclusive/blocked; report both decisions and gold coverage. claim_false_acceptance = gold-defective critical/material claims explicitly accepted by auditor / all gold-defective critical/material claims with a recorded auditor decision. Missing/nonfinal gold never assumed clean. An unresolved critical/material issue itself disqualifies safe approval. These are conditional error rates, not unconditional approval incidence.

Abstention categories per final reference: expected abstain + abstain = correct_abstention; expected answer + abstain = unnecessary_abstention; expected answer + answer with independently final supported/correct report = correct_substantive_answer; otherwise unsupported_confident_answer. Report counts, category rates / final expected decisions with recorded abstention, substantive_success = correct_substantive_answer / tasks expected answer. Always-abstain on answerable tasks has zero substantive success, not perfect reliability. No labels -> undefined.

Numerics: finite decimal strings only; identical declared canonical units required (no implicit conversions). Exact compares decimals after explicitly declared HALF_EVEN rounding if places present. Absolute: |a-r| <= tolerance. Relative: |a-r| <= tolerance*|r| (zero reference requires exact equality). Nonnegative finite tolerance, exact requires zero tolerance; relative tolerance <=1. Invalid/undefined reference calculations require explicit undefined=true and answer null, never NaN/Infinity. A provided non-null answer to an undefined calculation is incorrect. Missing judgment earns zero in numerical_correctness = correct final numerical judgments / all required numerical references. Numerical annotation coverage separately reported.

Operational trace fields are nullable nonnegative finite values: calls, input/output/reasoning tokens, tool calls, actual/estimated USD, seconds, retries, failures, human interventions, truncations, missing evidence, terminal status. Missing is null and enumerated; never infer free calls or zero cost. No token/model accuracy inference. Execution result records dataset/schema/scorer/candidate versions, configuration, optional explicit timestamp and environment; repeated identical inputs/config/metadata serialize identically (sort keys, no NaN).

## Statistics pre-specification

Task is the resampling unit; task-macro means across observed task scores. Deterministic percentile bootstrap (seed supplied, default 20261029; 2000 replicates; 95% interval), resample task IDs, not individual claims. n<2 has undefined CI. Report n, missing task IDs and effective coverage. Paired candidate-baseline uses complete paired task IDs only, candidate-minus-baseline, same resampled pairs; report excluded unpaired IDs. Domain strata separately; pooled descriptive task macro weights tasks equally, no population claim. Empty report metrics stay undefined and are not silently zero-filled; provide pessimistic sensitivity analysis separately in V17B. Unresolved labels treated missing for decisive factual accuracy, failures to establish support remain in support denominator. Minimum meaningful effect thresholds must be preregistered by human investigators before unblinding; no invented effect size here. Synthetic CI results test mechanics only; ~30 real tasks provide an initial diagnostic, not broad significance/generalization.

Engine citation binding: each scored citation names an actual engine source ID cited by its linked engine claim. The frozen source URL and full quote must match that source record. Every explicit engine citation relationship for an inventoried engine claim must be represented; neither evaluation-only citations nor omitted unfavorable citations are allowed. Unlisted summary-only propositions have no inferred engine citation. Narrative-only inline citation conventions require a separately reviewed adapter extension; no semantic link is invented. Independent claims outside the engine registry remain in the inventory and can receive missing-citation labels. Duplicate propositions are one claim ID with multiple exact locations (additional_locations), not multiple scoring units. Known engine claims are either inventoried or explicitly excluded as nonfactual with a reason; excluded text cannot be marked factual. Such exclusions still require independent semantic review. Rendering preserves all original field-string characters, including quotes, Unicode and newlines, in path-tagged lines; render_with_locations maps each field to exact report offsets. No normalization discards source offsets.
